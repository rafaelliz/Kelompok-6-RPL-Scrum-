# To-Do List Kelompok

## Deskripsi
To-Do List adalah aplikasi web sederhana yang digunakan
untuk mencatat dan mengelola daftar tugas pengguna.

Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript
sebagai bagian dari praktikum Rekayasa Perangkat Lunak (RPL)
dengan menerapkan metode Scrum serta kolaborasi Git dan GitHub.

## Fitur
- Menambahkan tugas baru.
- Menandai tugas yang sudah selesai.
- Menghapus tugas dengan klik dua kali.
- Menampilkan jumlah tugas dalam daftar.

## Cara Menjalankan
1. Clone repository ke komputer.
2. Buka folder repository.
3. Buka file `index.html` menggunakan browser.
4. Aplikasi siap digunakan.
